على Mac، استخدم **⌘** بدلاً من **Ctrl** في الاختصارات أدناه.

## اللوحات

| اللوحة | الغرض منها |
| --- | --- |
| **المستكشف** | الحزمة المفتوحة ومخططاتها. انقر مخططاً لتفتحه |
| **المكتبة** | كل العقد التي يمكنك إضافتها. ابحث فيها، أو اسحب عقدة إلى المخطط |
| **مخطط** | المكان الذي تبني فيه المادة |
| **الخصائص** | إعدادات العقدة المحددة، أو إعدادات المخطط |
| **عرض ثنائي الأبعاد** | نتيجة عقدة واحدة صورةً مسطحة |
| **عرض ثلاثي الأبعاد** | المادة كاملة على شكل أو نموذج |
| **وحدة التحكم** | الرسائل والتحذيرات والأخطاء |
| **السجل** | تغييراتك الأخيرة |

افتح اللوحات أو أغلقها من قائمة **نوافذ**. ويعيدها **نوافذ › إعادة ضبط التخطيط** إلى أماكنها الأصلية.

## الحزم والمخططات

الحزمة ملف <bdi>.sbs</bdi> واحد. ويمكن أن تضم عدة مخططات، إضافة إلى الصور التي تستخدمها.

- يضيف **ملف › جديد › مخطط...** مخططاً إلى الحزمة المفتوحة.
- يضيف **ملف › جديد › Function Graph...** مخطط دوال: مخططاً من العمليات الرياضية، يُحفظ في الحزمة.
- يبدأ **ملف › جديد › حزمة فارغة** من جديد بحزمة فارغة.
- يفتح **ملف › فتح...** حزمة <bdi>.sbs</bdi> أو مادة <bdi>.mcmat</bdi>.

## بناء المخطط

- وجّه المؤشر إلى المخطط واضغط **Space** أو **Tab** للبحث عن عقدة. وانقر المخطط بزر الماوس الأيمن لتجد **إضافة عقدة** وغيرها.
- اسحب من منفذ إخراج إلى منفذ إدخال لتصل عقدتين.
- انقر عقدة نقراً مزدوجاً لتعرضها في **عرض ثنائي الأبعاد**.
- حدد عقداً واختر **أدوات › إنشاء مخطط من التحديد** لتحويلها إلى مخطط مستقل.
- انقر المخطط بزر الماوس الأيمن لإضافة تعليق، أو إطار حول العقد المحددة، أو دبوس تنقل. وينقلك **F2** و**Shift+F2** بين الدبابيس.
- يشغّل **أدوات › Snap to grid** الالتقاط بالشبكة أو يوقفه.

| الإجراء | الطريقة |
| --- | --- |
| التكبير والتصغير | أدر عجلة الماوس |
| التحريك | اسحب بالزر الأوسط، أو **Alt**+سحب |
| تأطير كل شيء، أو التحديد | **F** |
| التكرار | **Ctrl+D** |
| الحذف | **Delete** |
| حذف عقدة وإعادة وصل أسلاكها | **Backspace** |
| تعطيل العقد المحددة | **Shift+D** |
| التراجع والإعادة | **Ctrl+Z**، **Ctrl+Y** |

### تحرير الأسلاك

- انقر سلكاً لتحدده. ويحدد **Shift**+نقر أو **Ctrl**+نقر المزيد.
- اضغط **Delete** لإزالة الأسلاك المحددة.
- حدد سلكين أو أكثر يدخلان إلى عقدة واضغط **X** لتبادل مصادرها. وفي عقدة **Blend** يبدّل هذا المقدمة والخلفية.
- اسحب سلكاً لتسحب منه نقطة إعادة توجيه. وانقر سلكاً نقراً مزدوجاً لتضع نقطة هناك.
- انقر سلكاً بزر الماوس الأيمن لتجد **Insert reroute dot** وبقية أوامر الأسلاك.

## استخدام مدخلات المخطط ومخرجاته

- عقد **Output** هي ما ينتجه المخطط. أعطِ كلاً منها استخداماً، مثل اللون الأساسي أو النواظم أو الخشونة. ويستخدمها العرض ثلاثي الأبعاد والتصدير.
- عقد **Input Color** و**Input Grayscale** و**Input Value** هي مدخلات المخطط. استخدمها لتغذيته بصورة أو قيمة من خارجه.

## كتابة دالة

تحسب **Pixel Processor** كل بكسل في صورتها بدالة. وتحسب **Value Processor** قيمة واحدة بدالة.

حدد العقدة، ثم اختر **Edit function** في **الخصائص**. في محرر الدوال تضيف العمليات، وتضبط الثوابت، وتصلها بالأسلاك، وتختار النتيجة.

## صنع نمط بعقدة FX-Map

تبني عقدة **FX-Map** صورة بوضع الأشكال وتكرارها.

1. حدد عقدة FX-Map واضغط **Ctrl+E** (**تحرير › Edit node graph**)، أو انقرها بزر الماوس الأيمن واختر **Edit graph**.
2. أضف في داخلها عقد **Quadrant** و**Switch** و**Iterate** و**Dot**. وصِلها من المنافذ السفلية إلى المنافذ العلوية.
3. انقر عقدة بزر الماوس الأيمن واختر **Set as root** لتجعلها بداية النمط.
4. اضغط **Alt+Left** (**تحرير › Parent graph**) لتعود إلى المخطط الرئيسي.

## ضبط المستويات

حدد عقدة **Levels**. تعرض **الخصائص** مدرجاً تكرارياً (histogram) لمدخل العقدة، وفوقه منحنى المستويات. اسحب المقابض تحت المدرج التكراري لتضبط نطاق الإدخال والدرجات المتوسطة، والمقابض تحت الشريط الرمادي لتضبط نطاق الإخراج. وتعطيك المنزلقات في الأسفل القيم بدقة.

## استخدام الصور

اختر **ملف › استيراد صورة نقطية...** لإضافة صورة إلى الحزمة. يقرأ MaterialCraft صيغ SVG وPNG وJPEG وTGA وTIFF وBMP وWebP وOpenEXR وRadiance HDR. استخدم الصورة في المخطط بعقدة **Bitmap** أو **رسوم متجهة (SVG)**. ويعيد **ملف › إعادة تحميل الموارد** قراءة الملفات بعد أن تغيّرها.

## معاينة مادتك

في **عرض ثنائي الأبعاد**، اعرض قناة واحدة (R أو G أو B أو A) أو القنوات كلها، أو شغّل المدرج التكراري، أو كرر الصورة ثلاثاً في ثلاث لتتحقق من حوافها. ويحفظ **حفظ الصورة...** ما تراه بصيغة PNG أو OpenEXR أو TGA.

وفي **عرض ثلاثي الأبعاد** قوائم خاصة به:

- **المشهد**: اختر شكلاً، أو حمّل نموذجك الخاص بصيغة OBJ أو glTF أو GLB بالأمر **تحميل مجسم...**، أو اختر **إعادة ضبط المشهد**.
- **الكاميرا** و**البيئة** و**عرض** و**المصير**: العرض، والإضاءة، وخيارات مثل التكرار وعمق الارتفاع والشفافية و**Flip normal map Y (DirectX)**.

يدير **Shift**+سحب في العرض ثلاثي الأبعاد الإضاءة. ويضع **أدوات › View outputs in 3D view** مخرجات المخطط على النموذج ثلاثي الأبعاد.

أثناء التحرير، تُحسب المعاينات بحجم أصغر لتبقى سريعة. غيّره في **أدوات › حجم المعاينة**.

## التصدير

- يكتب **ملف › تصدير المخرجات...** (**Ctrl+Shift+E**) كل مخرجات المخطط صوراً. اختر **المجلد** و**الصيغة** و**عمق البت** و**Resolution** (حتى 8192 بكسل) ونمط **أسماء الملفات**.
- يكتب **ملف › تصدير المادة...** ملف <bdi>.mcmat</bdi> محمولاً فيه الخرائط والمخطط معاً.

## التفضيلات

اختر **تحرير › التفضيلات...** لتضبط اللغة (الإنجليزية أو العربية)، والسطوع، ولون التمييز، وحجم الواجهة، وعدد مرات الحفظ التلقائي، وحجم المعاينة أثناء التحرير، والصور المصغرة للعقد، وطريقة تحريك العرض ثلاثي الأبعاد.

يسرد **مساعدة › قائمة الاختصارات...** كل الاختصارات.

## استخدامه مع مساعد ذكاء اصطناعي

في أداة سطر الأوامر الخاصة بـ MaterialCraft، `materialcraft-cli`، خادم [MCP](https://modelcontextprotocol.io)، فيستطيع Claude ومساعدو الذكاء الاصطناعي الآخرون بناء المخططات وضبط المعاملات وتصدير الخرائط. أعطِها المجلدات التي يمكنها القراءة منها والكتابة فيها:

```bash
claude mcp add materialcraft -- materialcraft-cli mcp --read-root . --write-root .
```

لترى تغييراته مباشرة، شغّل التطبيق بالأمر `materialcraft --control 7878`، ثم اتصل بالأمر `materialcraft-cli mcp --bridge 7878`.

وتعمل الأداة أيضاً وحدها. شغّل `materialcraft-cli --help` لترى ما يمكنها فعله، مثلاً:

```bash
materialcraft-cli new pbr my-material.sbs --size 2048
materialcraft-cli export my-material.sbs textures --format png --depth 16
materialcraft-cli render my-material.sbs preview.png --scene sphere
```
