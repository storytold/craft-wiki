يفتح PhotoCraft الملفات بالأمر **ملف › فتح…** ويحفظها بالأمر **ملف › حفظ باسم…**. ولإنشاء نسخة مسطّحة للمشاركة، مع معاينة وتقدير للحجم، استخدم **ملف › تصدير › تصدير باسم…** (راجع [تصدير صورة](/ar/apps/photocraft/workflows/#تصدير-صورة)).

يكتب PhotoCraft الصيغة التي يدل عليها امتداد اسم الملف، لذا تحقق من الامتداد حين تحفظ.

## المستندات متعددة الطبقات

هذه الصيغ تحتفظ بطبقاتك.

| الصيغة | الامتداد | فتح | حفظ |
| --- | --- | --- | --- |
| PhotoCraft | `.pcraft` | نعم | نعم |
| Photoshop | `.psd`، `.psb` | نعم | نعم |
| TIFF مع الطبقات | `.tif`، `.tiff` | نعم | نعم |
| OpenRaster | `.ora` | نعم | نعم |
| GIMP | `.xcf` | نعم | لا |
| Krita | `.kra`، `.krz` | نعم | لا |
| Paint.NET | `.pdn` | نعم | لا |
| Affinity | `.af`، `.afphoto`، `.afdesign`، `.afpub` | نعم | لا |
| SVG | `.svg`، `.svgz` | نعم، كطبقات أشكال | لا |

**PSD وPSB.** يفتح PhotoCraft ملفات PSD وPSB متعددة الطبقات ويحفظها، ومنها مستندات 16 بت و32 بت وCMYK وLab. وتبقى طبقات النص قابلة للتحرير. وحين يعيد حفظ ملف PSD، يحتفظ بالأجزاء التي لا يفهمها بعد بدلاً من إسقاطها. يبدو الملف المحفوظ كما هو، لكنه لا يطابق الملف الذي فتحته بايتاً ببايت.

**الملفات من المحررات الأخرى.** تُفتح ملفات GIMP وKrita وPaint.NET وAffinity مع طبقاتها، لكن PhotoCraft لا يستطيع حفظها. لتواصل تحرير ملف Krita أو GIMP في التطبيقين، احفظه بصيغة OpenRaster (`.ora`)، فكلاهما يفتحها مع طبقاتها. وإذا استخدم الملف شيئاً لا يستطيع PhotoCraft مطابقته، مثل بعض تأثيرات Affinity، فإن PhotoCraft يخبرك بما أسقطه أو قرّبه.

## الصور المسطّحة

هذه الصيغ تحمل صورة واحدة دون طبقات.

| الصيغة | فتح | حفظ باسم | تصدير باسم |
| --- | --- | --- | --- |
| PNG | نعم | نعم | نعم |
| JPEG | نعم | نعم | نعم |
| WebP | نعم | نعم | نعم |
| TIFF | نعم | نعم | نعم |
| Targa (`.tga`) | نعم | نعم | نعم |
| ICO | نعم | نعم | نعم |
| JPEG XL (`.jxl`) | لا | نعم | نعم |
| GIF وBMP | نعم | نعم | |
| OpenEXR وRadiance HDR | نعم | نعم | |
| FITS (صور فلكية) | نعم | نعم | |
| DDS (خامات الألعاب) | نعم | نعم | |
| DPX وCineon | نعم | نعم | |
| Netpbm (`.pnm`، ويفتح أيضاً `.pbm` و`.pgm` و`.ppm` و`.pam` و`.pfm`) | نعم | نعم | |
| Amiga IFF | نعم | نعم | |
| PDF | لا | نعم | |
| صور HEIC وHEIF | نعم | لا | |
| ملفات الكاميرا الخام: DNG وCR2 وCR3 وNEF وNRW وARW وPEF وORF وRW2 وRAF | نعم | لا | |
| QOI وPCX وXPM وDICOM | نعم | لا | |

يُحفظ JPEG XL دون فقدان. ولا تستطيع JPEG وWebP وغيرها من صيغ 8 بت أن تحمل 16 أو 32 بت لكل قناة، لذا ينبهك PhotoCraft حين يخفّض العمق. ويحتفظ PNG بعمق 16 بت، ويحتفظ TIFF وOpenEXR بالأعداد العشرية بعمق 32 بت.

حين تحفظ فوق ملف JPEG فتحته باستخدام **ملف › حفظ**، يحافظ PhotoCraft على جودته. ويبقى ملف WebP بضغط مع فقدان أو دون فقدان، كما كان.

## الفرش وعينات الألوان والإعدادات المسبقة الأخرى

يحمّل **ملف › فتح…** أيضاً إعدادات مسبقة من تطبيقات أخرى:

| النوع | الامتداد |
| --- | --- |
| الفُرش | `.abr` |
| التدرجات | `.grd` |
| أنماط الطبقة | `.asl` |
| عينات الألوان | `.aco`، `.act`، `.ase` |
| اختصارات لوحة المفاتيح | `.kys` |

## في نافذة الملفات

تسرد نافذة **فتح** الخيار **All Formats** أولاً، ثم عنصراً لكل صيغة، فيمكنك أن تقصر عرض مجلد فيه ملفات مختلطة على نوع واحد. وتسرد نافذة **حفظ باسم** الخيار **PSD Document** أولاً، أما مستند `.pcraft` فيكون نوعه الافتراضي **PhotoCraft**.
