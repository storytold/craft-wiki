كل شيء في CADCraft أمر، لذا كل ما تفعله يدوياً يمكنك أن تكتب له سكربتاً. تعمل السكربتات وروتينات LISP داخل التطبيق. أما أداة `cadcraft-cli` فتشغّل CADCraft دون نافذة، وتتيح لوكلاء الذكاء الاصطناعي الرسم عبر MCP.

## تشغيل سكربت

السكربت (`.scr`) ملف نصي فيه ما كنت ستكتبه في سطر الأوامر، سطراً بعد سطر. اختر **أدوات › تشغيل برمجية...** لتشغيله.

## تحميل روتينات LISP

يشغّل CADCraft روتينات AutoLISP (`.lsp`). اختر **أدوات › تحميل تطبيق...**، أو اكتب `(load "name")` في سطر الأوامر. معظم الروتينات التي ترسم وتحرّر وتطلب نقاطاً أو كائنات تعمل كما هي.

لتحميل الروتينات في كل مرة، ضعها في مجلد `support` داخل مجلد إعدادات CADCraft، وحمّلها من ملف `acad.lsp` أو `acaddoc.lsp` هناك:

| النظام | مجلد الدعم |
| --- | --- |
| Windows | `%APPDATA%\CADCraft\support\` |
| macOS | `~/Library/Application Support/CADCraft/support/` |
| Linux | `~/.config/cadcraft/support/` |

لا يُبحث أبداً في مجلد الرسم نفسه، لذا لا يعمل ملف `acaddoc.lsp` جاء مع رسم نزّلته.

:::note
غير مدعوم بعد: دوال Visual LISP من نوع ActiveX (`vlax-…` و`vla-…`)، ونوافذ DCL، والمستجيبات (reactors)، وملفات `.fas` و`.vlx` المترجمة، والإضافات المكتوبة بـ <bdi>C++</bdi> أو <bdi>.NET</bdi>.
:::

## تغيير اختصارات الأوامر

اختر **أدوات › تخصيص › تحرير اختصارات الأوامر (PGP)...** لإضافة الاختصارات أو تغييرها أو إزالتها. ويحمّل **استيراد…** ملف اختصارات `.pgp` من برنامج CAD آخر. وتبقى اختصاراتك بعد إعادة التشغيل.

## استخدام cadcraft-cli

تأتي `cadcraft-cli` مع حزم Windows وLinux. أما على macOS فتُنزَّل منفصلة: راجع [التثبيت والتحديث](/ar/apps/cadcraft/install-update/#macos). ولها خمسة أوامر فرعية:

| الأمر الفرعي | ما يفعله |
| --- | --- |
| `info` | يصف الرسم: طبقاته وكتله وكائناته وغيرها، بصيغة JSON |
| `convert` | يحوّل الرسم، مثلاً من DWG إلى DXF، أو من DXF إلى SVG أو PNG أو PDF |
| `run` | يفتح رسماً، ويشغّل أوامر أو سكربتاً، ويحفظ النتيجة أو يصدّرها |
| `commands` | يسرد كل الأوامر ومعاملاتها |
| `mcp` | يشغّل خادم MCP لوكلاء الذكاء الاصطناعي |

مثلاً:

```sh
cadcraft-cli info drawing.dxf
cadcraft-cli convert drawing.dwg drawing.pdf
cadcraft-cli run drawing.dxf --script-file setup.scr --save out.dxf
```

يسرد `cadcraft-cli --help` كل الخيارات.

## دع وكيل ذكاء اصطناعي يرسم

في CADCraft خادم [MCP](https://modelcontextprotocol.io)، فيستطيع أي مساعد ذكاء اصطناعي يدعم MCP أن يرسم ويحرّر به. يستطيع الوكيل أن يكتب في سطر الأوامر كما يفعل الإنسان، وأن يشغّل أي أمر، وأن يقرأ ما في الرسم ليتحقق من عمله، وأن ينظر إلى صورة له.

لتعطي الوكيل رسماً خاصاً به، دون نافذة، أضف هذا إلى إعدادات عميل MCP لديك:

```json
{ "mcpServers": { "cadcraft": { "command": "cadcraft-cli", "args": ["mcp"] } } }
```

ولتشاهد الوكيل يعمل داخل التطبيق بدلاً من ذلك:

1. شغّل CADCraft بمنفذ تحكم: `cadcraft --control 7979`.
2. وجّه عميل MCP إليه، بالقيمة `"args": ["mcp", "--connect", "127.0.0.1:7979"]`.

لا يستمع منفذ التحكم إلا على حاسوبك أنت. ويستطيع الوكيل حينها أيضاً أن يلتقط صوراً للشاشة وأن ينقر في التطبيق.
