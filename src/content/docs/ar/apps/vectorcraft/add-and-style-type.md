يشرح هذا الدليل كيف تضيف أنواع النص الثلاثة في VectorCraft، وتجعل نصاً متصلاً واحداً يتدفق عبر عدة إطارات، وتضبط خط النص وحجمه وتباعده ومحاذاته. وينتهي بتحويل الحروف إلى مسارات لعمل فني لم يعد يحتاج إلى التحرير كنص. تُظهر الصورة التالية مثالاً على كل نوع من أنواع النص في مستند واحد.

![ملصق غروب فيه أنواع النص الثلاثة: العنوان Golden Hour مكتوب كنص نقطة، وفقرة تلتف داخل إطار مستطيل، والسطر OPEN UNTIL MIDNIGHT يمتد على قوس فوق الشمس. السطر الذي على القوس محدد](/assets/uploads/vectorcraft/type-kinds.webp)

## أنواع النص

| النوع | طريقة إنشائه | ما يحدد شكله |
|---|---|---|
| **نص النقطة** (point type) | انقر بأداة Type واكتب. | لا يلتف نص النقطة. ينتهي كل سطر حيث تضغط Enter. |
| **نص المساحة** (area type) | اسحب إطاراً بأداة Type، أو انقر محيط مسار مغلق. | يلتف النص عند حواف الإطار. ويضبط **Type → Area Type Options…** الصفوف والأعمدة والفواصل والهامش الداخلي. |
| **النص على مسار** (type on a path) | انقر محيط مسار مفتوح بأداة Type، أو انقر أي مسار بأداة Type on a Path. | يتبع النص المسار. اسحب أقواس البداية والمنتصف والنهاية، أو اضبط الخيارات في **Type → Type on a Path → Type on a Path Options…**. |

## إضافة نص النقطة

1. اختر أداة Type (T).
2. انقر جزءاً فارغاً من لوح الرسم واكتب.
3. اضغط Enter لبدء سطر جديد.
4. انقر جزءاً فارغاً من مساحة الرسم لإنهاء التحرير. والنقرة التالية تنشئ نصاً جديداً.

إن نقرت لوضع نص نقطة وتركته فارغاً، يزيله VectorCraft حين تنهي التحرير.

## إضافة نص المساحة

1. اختر أداة Type (T).
2. اسحب على لوح الرسم لترسم إطاراً، ثم اكتب. يلتف النص حين يبلغ حافة الإطار.
3. لوضع النص داخل شكل رسمته من قبل، انقر محيط المسار المغلق بأداة Type بدلاً من ذلك. يصبح المسار هو الإطار، وتُزال تعبئته وحده.
4. والنص محدد، اختر **Type → Area Type Options…** لتضبط عدد الصفوف والأعمدة، والفاصل بينها، والهامش الداخلي من حافة الإطار، وخط الأساس الأول، والمحاذاة الرأسية للأسطر، وطريقة ملاءمة الإطار لنصه (**None** أو **Auto Size** أو **Shrink Text to Fit**).

لتبديل كائن نص محدد بين النوعين، اختر **Type → Convert To Area Type** أو **Type → Convert To Point Type**. وتحويل نص المساحة إلى نص نقطة يحوّل كل التفاف تلقائي للسطر إلى فاصل أسطر.

:::tip
يُظهر كائن النص المحدد دائرة صغيرة بجانب الجهة اليمنى من مربعه المحيط: مفرغة في نص النقطة ومصمتة في نص المساحة. انقر الدائرة نقراً مزدوجاً بأداة Selection لتحويل النص إلى النوع الآخر. ويبقى النص وأنماطه كما هي.
:::

## وضع النص على مسار

1. ارسم مساراً بأداة Pen أو Curvature أو Pencil، أو استخدم شكلاً.
2. اختر أداة Type وانقر محيط مسار مفتوح. ولمسار مغلق، اختر أداة Type on a Path من مجموعة أداة Type وانقر المحيط.
3. اكتب النص. يمتد النص على المسار، وتُزال تعبئة المسار وحده.
4. انتقل إلى أداة Selection أو Direct Selection. يُظهر النص المحدد قوس بداية وقوس منتصف وقوس نهاية.
5. اسحب قوس البداية أو النهاية لتحدد أين يبدأ النص أو ينتهي على المسار.
6. اسحب قوس المنتصف على امتداد المسار لتزلق النص. واسحبه عبر المسار لتقلب النص إلى الجهة الأخرى. أبقِ **Ctrl** مضغوطاً (**Cmd** على macOS) أثناء السحب لتزلق النص دون قلبه.

تطبّق القائمة الفرعية **Type → Type on a Path** تأثيراً يغيّر طريقة جلوس كل حرف على المسار: **Rainbow** أو **Skew** أو **3D Ribbon** أو **Stair Step** أو **Gravity**. ويضبط **Type → Type on a Path → Type on a Path Options…** التأثير، والقلب، و**Align to Path** (**Ascender** أو **Descender** أو **Center** أو **Baseline**)، والتباعد.

## تدفق النص بين الإطارات

النص المتسلسل (threaded text) نص متصل واحد يتدفق عبر عدة إطارات بالترتيب. ويمكن تسلسل نص المساحة والنص على مسار بأي خليط بينهما.

1. حدد إطارين أو أكثر من نص المساحة، أو كائنات نص على مسار، أو مسارات مغلقة.
2. اختر **Type → Threaded Text → Create**.

يسلسل VectorCraft الكائنات بحسب ترتيب التكديس. وتصبح المسارات المغلقة في التحديد إطارات نص مساحة. والنص الذي لا يتسع له إطار واحد يكمل في الإطار التالي. تُظهر الصورة التالية نصاً واحداً يتدفق عبر إطارين، مع خط التسلسل الذي يصل بينهما.

![منشور لسوق ليلي فيه مظلات مخططة وأضواء زينة وإطارا نص متجاوران. يتدفق نص واحد من الإطار الأول إلى الثاني، ويصل خط تسلسل منفذ الخروج في الإطار الأول بمنفذ الدخول في الإطار الثاني](/assets/uploads/vectorcraft/threaded-text.webp)

ويمكنك أيضاً التسلسل من إطار واحد بأداة Selection:

1. حدد نص المساحة أو النص على مسار. يُظهر منفذ دخول ومنفذ خروج.
2. انقر منفذ الخروج. يُحمَّل المؤشر بالنص.
3. انقر مساراً مغلقاً أو كائن نص آخر ليتدفق النص إليه، أو انقر مساحة رسم فارغة لإنشاء إطار جديد من النوع والشكل والحجم نفسه، أو اسحب لترسم مستطيلاً للإطار الجديد.

النقر على منفذ الدخول يعمل بالطريقة نفسها، إلا أن الإطار الجديد يأتي قبل الإطار المنقور في التسلسل. اضغط Escape لإسقاط النص المحمّل.

لإلغاء التسلسل:

- يُخرج **Type → Threaded Text → Release Selection** الإطارات المحددة من تسلسلها. ويستمر النص في التدفق عبر الإطارات الباقية.
- يقطع **Type → Threaded Text → Remove Threading** تسلسل الإطارات المحددة. ويحتفظ كل إطار بالنص الذي يعرضه.

يخفي **View → Hide Text Threads** (**Ctrl+Shift+Y**، أو **Cmd+Shift+Y** على macOS) الخطوط المرسومة بين الإطارات المتسلسلة. اختره مرة أخرى لإظهارها.

## ضبط الخط والحجم والتباعد

تنسّق لوحة Character (**Window → Type → Character**؛ **Ctrl+T**، أو **Cmd+T** على macOS) كائنات النص المحددة، أو الأحرف التي حددتها بأداة Type. حدد كائن نص أولاً؛ فإن لم يكن شيء محدداً، تعرض اللوحة «<bdi>Select a text object to edit its character attributes.</bdi>» تُظهر لقطة الشاشة التالية اللوحة والعنوان المكتوب كنص نقطة محدد.

![لوحة Character بجانب العنوان المحدد Golden Hour على ملصق غروب، مضبوطة على الخط Source Serif 4 Regular بحجم 54 pt وتباعد أسطر 64.8 pt، تليها حقول Kerning وTracking والمقياس وإزاحة خط الأساس والتدوير، وصف أزرار الأنماط، وقائمة Language](/assets/uploads/vectorcraft/character-panel.webp)

تضم اللوحة عناصر التحكم التالية. مرّر المؤشر فوق الأيقونة التي بجانب الحقل لترى اسمه.

| عنصر التحكم | ما يضبطه |
|---|---|
| عائلة الخط ونمطه | الخط ووزنه أو نمطه |
| **Font Size** | حجم الأحرف |
| **Leading** | المسافة بين الأسطر |
| **Kerning** | المسافة بين حرفين متجاورين؛ و**Optical** أحد خياراته |
| **Tracking** | المسافة على امتداد مجموعة من الأحرف |
| **Vertical Scale %** و**Horizontal Scale %** | التمديد الرأسي أو الأفقي للأحرف |
| **Baseline Shift** | مقدار ارتفاع الأحرف أو انخفاضها عن خط الأساس |
| **Character Rotation** | تدوير كل حرف |
| **All Caps**، **Small Caps**، **Superscript**، **Subscript**، **Underline**، **Strikethrough** | أزرار تشغّل كل نمط أو توقفه |
| **Language** | اللغة التي تُشكَّل بها الأحرف، ليستخدم الخط أشكال الحروف الخاصة بتلك اللغة |

يخفي **Hide Options** في قائمة اللوحة كل الصفوف التي تحت حقول الحجم وتباعد الأسطر وKerning وTracking، ويُظهرها **Show Options** مجدداً. وفي قائمة اللوحة أيضاً **Reset Panel**.

أثناء تحرير نص أفقي بأداة Type، يغيّر مفتاح Alt (Option على macOS) مع مفاتيح الأسهم التباعد بالمقادير المضبوطة في **Preferences → Type**:

- يغيّر **Alt+Left** و**Alt+Right** (**Option+Left** و**Option+Right** على macOS) قيمة Kerning عند مؤشر الكتابة، أو قيمة Tracking للنص المحدد.
- يغيّر **Alt+Up** و**Alt+Down** (**Option+Up** و**Option+Down** على macOS) تباعد الأسطر.
- يغيّر **Alt+Shift+Up** و**Alt+Shift+Down** (**Option+Shift+Up** و**Option+Shift+Down** على macOS) إزاحة خط الأساس.

## محاذاة الفقرات

تضبط لوحة Paragraph (**Window → Type → Paragraph**؛ **Ctrl+Alt+T**، أو **Cmd+Option+T** على macOS) المحاذاة والمسافات البادئة والمسافة حول الفقرات. أزرار المحاذاة فيها هي **Align left** و**Align center** و**Align right** و**Justify with last line aligned left** و**Justify with last line aligned center** و**Justify with last line aligned right** و**Justify all lines**. وتحتها **Left Indent** و**Right Indent** و**First-line Left Indent** و**Space Before Paragraph** و**Space After Paragraph**، وخيار **Hyphenate**. وإن لم يكن شيء محدداً، تعرض اللوحة «<bdi>Select a text object to edit its paragraph attributes.</bdi>»

تُطبَّق المحاذاة على فقرات النص المحدد، أو على الفقرات التي يلمسها تحديد أداة Type.

ويفتح **Window → Type** أيضاً لوحات **Character Styles** و**Paragraph Styles** و**Glyphs** و**OpenType** و**Tabs**.

## استخدام قائمة Type

| الأمر | ما يفعله |
|---|---|
| **Font** و**Recent Fonts** | اختيار عائلة خط، أو خط استخدمته مؤخراً |
| **Size** | اختيار حجم خط من قائمة أحجام بالنقاط |
| **Glyphs** | فتح لوحة Glyphs |
| **Insert Special Character** | إدراج علامة تعداد نقطي، أو علامة حقوق النشر، أو العلامة المسجلة، أو العلامة التجارية، أو علامة القسم أو الفقرة، أو علامة الحذف، أو الشرطات، أو الواصلات، أو علامات الاقتباس المنحنية |
| **Fit Headline** | ضبط تباعد أحرف السطر الأول من نص المساحة ليملأ عرض الإطار |
| **Find Font…** | سرد الخطوط التي يستخدمها المستند، وتمييز المفقود منها، واستبدال خط بآخر |
| **Change Case** | تغيير حالة أحرف النص المحدد إلى **UPPERCASE** أو **lowercase** أو **Title Case** أو **Sentence case** |
| **Smart Punctuation…** | استبدال علامات الاقتباس المستقيمة بعلامات الاقتباس المضبوطة في Document Setup، و`--` و`---` بالشرطة القصيرة والطويلة، و`...` بحرف علامة الحذف، في التحديد أو في المستند كله |
| **Bullets and Numbering** | **Apply Bullets** أو **Apply Numbers** أو **Convert to Text** لتحويل علامات القوائم إلى نص عادي |
| **Fill with Placeholder Text** | استبدال النص المحدد بنص مؤقت؛ ويُملأ نص المساحة حتى إطاره |
| **Show Hidden Characters** | إظهار علامات للمسافات ونهايات الفقرات ونهايات النصوص المتصلة |

## تحويل النص إلى أشكال

يحوّل **Type → Create Outlines** (**Ctrl+Shift+O**، أو **Cmd+Shift+O** على macOS) النص المحدد إلى مجموعات من المسارات المركبة، مساراً لكل حرف. ويمكنك بعدها تحرير الحروف بأدوات المسارات.

:::caution
بعد Create Outlines، تصبح الحروف مسارات، ولا يعود بإمكانك تحرير الكلمات أو تغيير الخط. أنشئ نسخة مكررة من النص قبل تحويله، واحتفظ بها على طبقة مخفية إن احتجت إلى تغيير النص لاحقاً.
:::

إطار النص المتسلسل الذي تحوّله يخرج من تسلسله، ولا يحتفظ إلا بالنص الذي يعرضه.
