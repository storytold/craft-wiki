في هذه الصفحة ترسم المسارات بأدوات Pen وCurvature وPencil ثم تغيّر شكلها. تحرّك نقاط الارتكاز ومقابض الاتجاه بأداة Direct Selection، وتقص المسارات بأداتي Scissors وKnife، وتستخدم الأوامر الموجودة في قائمة **Object → Path**.

## كيف يُبنى المسار

المسار خط مكوّن من مقاطع. يمتد كل مقطع بين نقطتي ارتكاز. وللمقطع المنحني أيضاً مقابض اتجاه عند نقطتي ارتكازه، ويحدد طول كل مقبض وزاويته شكل المنحنى.

لنقطة الارتكاز الناعمة مقبضان يبقيان على استقامة واحدة، فيمر المسار بها دون انكسار. أما نقطة الارتكاز الزاوية فليس لها مقابض، أو لها مقابض يتحرك كل منها وحده، فيغيّر المسار اتجاهه عندها. تُظهر الصورة التالية مساراً فيه نقطة ارتكاز ناعمة في الوسط ونقطة ارتكاز زاوية عند كل طرف.

![خط قمم جبلية منحنٍ فوق سماء الغروب فيه ثلاث نقاط ارتكاز. النقطة الوسطى ناعمة، ولها مقبضا اتجاه على استقامة واحدة، وتشير تسميات إلى نقطة ارتكاز ومقبض اتجاه ومقطع](/assets/uploads/vectorcraft/path-anatomy.webp)

## أدوات المسارات

| الأداة | المفتاح | ما تفعله |
|---|---|---|
| **Pen** | P | تضع نقطة ارتكاز زاوية حيث تنقر، ونقطة ارتكاز ناعمة حيث تسحب |
| **Add Anchor Point** | + | تضيف نقطة ارتكاز حيث تنقر على مقطع، دون أن تغيّر الشكل |
| **Delete Anchor Point** | - | تزيل نقطة الارتكاز التي تنقرها وتعيد ملاءمة المنحنى حولها |
| **Anchor Point** | Shift+C | تحوّل نقاط الارتكاز بين ناعمة وزاوية، وتحرّك مقبضاً واحداً وحده |
| **Curvature** | <bdi>Shift+~</bdi> | ترسم مساراً ينحني مارّاً بكل نقطة تنقرها |
| **Pencil** | N | ترسم مساراً حيث تسحب |
| **Direct Selection** | A | تحدد نقاط الارتكاز والمقاطع والمقابض وتحرّكها |
| **Scissors** | C | تقسم المسار حيث تنقره |

أدوات Add Anchor Point وDelete Anchor Point وAnchor Point موجودة في مجموعة أداة Pen في لوحة Tools. وتشترك أداتا Smooth وPath Eraser في مجموعة واحدة مع Pencil، أما Scissors وKnife ففي مجموعة أداة Eraser. يمكنك تغيير هذه المفاتيح من **Edit → Keyboard Shortcuts…**.

## الرسم بأداة Pen

1. اضغط P لاختيار أداة Pen.
2. انقر لوضع نقطة ارتكاز زاوية. ثم انقر مرة أخرى في مكان آخر لترسم مقطعاً مستقيماً إليه.
3. لوضع نقطة ارتكاز ناعمة، اضغط واسحب. يسحب السحب مقبضيها ويحني المقطع.
   - أبقِ **Alt** مضغوطاً (**Option** على macOS) أثناء السحب لتفصل المقبضين. يبقى المقبض الداخل في مكانه، ولا يتبع المؤشر إلا المقبض الخارج.
   - أبقِ Shift مضغوطاً لتُبقي المقبض بخطوات قدرها 45°.
   - أبقِ Space مضغوطاً لتحرّك نقطة الارتكاز مع مقبضيها.
4. لإغلاق المسار، انقر نقطة الارتكاز الأولى. ولتترك المسار مفتوحاً، اضغط Enter أو Esc.
5. للإضافة إلى مسار مفتوح لاحقاً، انقر أحد طرفيه بأداة Pen وتابع الرسم.

أثناء الرسم، تتبع معاينة المقطع التالي المؤشر. وحين تنقر آخر نقطة ارتكاز وضعتها، تزيل أداة Pen مقبضها الخارج، فيخرج المقطع التالي من تلك النقطة كزاوية.

![أداة Pen في منتصف رسم قمم جبلية فوق الغروب: نقطة ارتكاز زاوية، ونقطة ارتكاز ناعمة سُحب مقبضاها، ومعاينة المقطع التالي تتبع المؤشر مع قراءة المسافة والزاوية. ويعرض شريط الحالة تلميحات أداة Pen](/assets/uploads/vectorcraft/pen-drawing.webp)

:::tip
حين يكون مسار محدداً ولا ترسم مساراً، تضيف أداة Pen نقطة ارتكاز حيث تنقر أحد مقاطعه، وتحذف نقطة الارتكاز التي تنقرها. أبقِ Shift مضغوطاً لتبدأ مساراً جديداً بدلاً من ذلك. لإيقاف هذا السلوك، افتح **Edit → Preferences…**، واختر صفحة General وشغّل **Disable Auto Add/Delete**.
:::

:::note
أثناء الرسم، انقر طرف مسار مفتوح آخر لتصل المسارين في مسار واحد.
:::

## الرسم بأداة Curvature

تضع أداة Curvature نقاطاً، وينحني المسار بنعومة مارّاً بها كلها.

1. اضغط <bdi>Shift+~</bdi> لاختيار أداة Curvature.
2. انقر لوضع كل نقطة. يتحدّث المنحنى كلما أضفت نقاطاً.
3. لتجعل نقطة زاوية، انقرها مع الضغط على Alt (على Option في macOS) أو انقرها نقراً مزدوجاً. وكرر ذلك لتجعلها ناعمة.
4. لتحريك نقطة، اسحبها.
5. لإزالة آخر نقطة وضعتها أو حرّكتها، اضغط Backspace أو Delete.
6. لإغلاق المسار، انقر النقطة الأولى. ولتترك المسار مفتوحاً، اضغط Esc أو Enter.

تحرّر أداة Curvature أيضاً أي مسار محدد، أياً كانت الأداة التي رسمته. انقر مقطعاً لتضيف نقطة ناعمة دون تغيير الشكل، واسحب نقطة لتحرّكها. لا يتغير إلا المقطعان المتصلان بتلك النقطة.

## الرسم الحر بأداة Pencil

1. اضغط N لاختيار أداة Pencil.
2. اسحب لترسم. يرسم VectorCraft مساراً يطابق حركتك حين تحرر زر الماوس.
3. لإغلاق المسار، أنهِ الحركة قرب بدايتها، أو أبقِ **Alt** مضغوطاً (**Option** على macOS) وأنت تحرر الزر.

لمتابعة مسار مفتوح، حدده وابدأ حركتك قرب أحد طرفيه. ولرسم خط مستقيم بخطوات قدرها 45°، أبقِ Shift مضغوطاً حين تبدأ السحب.

وفي مجموعة أداة Pencil أداتان أخريان تغيّران مسارات رسمتها من قبل:

- تنعّم **Smooth** المسارات المحددة على امتداد الجزء الذي تسحب فوقه.
- تمحو **Path Eraser** أجزاء المسارات المحددة التي تسحب فوقها.

## الرسم بأداتي Paintbrush وBlob Brush

- ترسم أداة **Paintbrush** (B) مساراً حراً حيث تسحب، مثل Pencil. ومع لوح رسم رقمي، تسجل أيضاً ضغط القلم على امتداد الحركة.
- ترسم أداة **Blob Brush** (**Shift+B**) أشكالاً معبأة بدلاً من مسارات ذات حد. اضغط <bdi dir="ltr">[</bdi> أو <bdi dir="ltr">]</bdi> وهي نشطة لتصغير رأسها أو تكبيره.

## تحرير نقاط الارتكاز بأداة Direct Selection

1. اضغط A لاختيار أداة Direct Selection.
2. انقر نقطة ارتكاز لتحديدها. وانقر مع الضغط على Shift لتضيف نقاط ارتكاز أخرى إلى التحديد، أو لتزيل واحدة منه.
3. اسحب نقطة ارتكاز محددة لتحرّك نقاط الارتكاز المحددة. وأبقِ Shift مضغوطاً لتُبقي الحركة بخطوات قدرها 45°.
4. انقر مقطعاً لتحدد ذلك المقطع وحده.
5. اسحب مقبض اتجاه لتغيير المنحنى. أبقِ Shift مضغوطاً لتُبقي المقبض بخطوات قدرها 45° حول نقطة ارتكازه، أو أبقِ **Alt** مضغوطاً (**Option** على macOS) لتحرّك ذلك المقبض وحده.
6. لتحديد عدة نقاط ارتكاز معاً، اسحب مستطيل تحديد حولها.

تُظهر لقطة الشاشة التالية نقاط الارتكاز ومقابض هلال محدد بأداة Direct Selection.

![أداة Direct Selection تُظهر نقاط الارتكاز ومقابض المنحنى لهلال بنفسجي، وتحته شريط Contextual Task Bar يعرض Offset Path وSimplify وDuplicate](/assets/uploads/vectorcraft/paths.webp)

تحوّل أداة Anchor Point (Shift+C) نقاط الارتكاز:

- انقر نقطة ارتكاز ناعمة لتجعلها زاوية.
- اسحب نقطة ارتكاز لتسحب منها مقبضين ناعمين.
- اسحب مقبضاً لتحرّكه وحده.
- اسحب مقطعاً لتغيير انحنائه.

:::tip
وأداة Pen نشطة، أبقِ **Alt** مضغوطاً (**Option** على macOS) فوق مقبض أو نقطة ارتكاز أو مقطع في مسار محدد لتستخدمه كأداة Anchor Point دون تبديل الأداة.
:::

## قص المسارات

- بأداة **Scissors** (C)، انقر المسار حيث تريد قصه. ينفتح المسار المغلق عند تلك النقطة، ويصبح المسار المفتوح مسارين.
- بأداة **Knife**، اسحب عبر الأشكال المغلقة لتقصها على امتداد السحب. تقص Knife الأشكال المحددة، أو كل الأشكال إن لم يكن شيء محدداً. أبقِ **Alt** مضغوطاً (**Option** على macOS) حين تبدأ السحب لتقص على خط مستقيم، وأبقِ Shift مضغوطاً أيضاً لتُبقي ذلك الخط بخطوات قدرها 45°.

## أوامر Object → Path

حدد مساراً واحداً أو أكثر، ثم اختر أمراً من **Object → Path**. يعمل <bdi>Clean Up…</bdi> على المستند كله ولا يحتاج إلى تحديد.

| الأمر | Windows وLinux | macOS | ما يفعله |
|---|---|---|---|
| **Join** | Ctrl+J | Cmd+J | يصل مسارين مفتوحين أو أكثر في مسار واحد، أو يغلق مساراً مفتوحاً واحداً |
| **Average…** | Ctrl+Alt+J | Cmd+Option+J | ينقل نقاط الارتكاز المحددة إلى موضعها المتوسط، أفقياً أو رأسياً أو كليهما |
| **Average & Join…** | Ctrl+Alt+Shift+J | Cmd+Option+Shift+J | ينقل طرفين مفتوحين إلى النقطة التي بينهما ويصلهما هناك، في خطوة واحدة |
| **Outline Stroke** | | | يستبدل بالمسار ذي الحد شكلاً معبأً بحجم الحد |
| **Offset Path…** | | | يضيف مساراً جديداً على مسافة محددة خارج الأصلي، أو داخله بقيمة Offset سالبة، بوصلات Miter أو Round أو Bevel |
| **Reverse Path Direction** | | | يعكس اتجاه المسارات المحددة |
| **Simplify…** | | | يقلل عدد نقاط الارتكاز مع إبقاء الشكل قريباً من الأصل |
| **Smooth…** | | | ينعّم المسارات المحددة بمقدار تضبطه بشريط تمرير |
| **Add Anchor Points** | | | يضيف نقطة ارتكاز في منتصف كل مقطع دون تغيير الشكل |
| **Remove Anchor Points** | | | يزيل نقاط الارتكاز التي حددتها بأداة Direct Selection، دون أن يفتح المسار |
| **Divide Objects Below** | | | يقص الكائنات الواقعة تحت المسار المحدد به، ثم يزيل ذلك المسار |
| **Split Into Grid…** | | | يستبدل بالمسارات المحددة شبكة من المستطيلات، بالصفوف والأعمدة والفواصل التي تضبطها |
| **Clean Up…** | | | يحذف النقاط الشاردة والكائنات غير الملوّنة ومسارات النص الفارغة |

يضع <bdi>Offset Path…</bdi> المسار الجديد فوق الأصلي. وفي نافذته الحقول **Offset** و**Joins** و**Miter Limit**. تُظهر الصورة التالية، من اليسار إلى اليمين، مساراً ذا حد، والمسار نفسه بعد Outline Stroke، ومساراً خلفه مسار إزاحة مدوّر.

![ثلاث نجوم في سماء ليلية عليها التسميات Stroked path وOutline Stroke وOffset Path: محيط نجمة بحد كهرماني بسيط، والنجمة نفسها بعد أن حوّل Outline Stroke حدها إلى شكل معبأ، وهي محددة فتظهر نقاط ارتكازها الجديدة، ونجمة مرجانية خلفها مسار إزاحة بنفسجي مدوّر](/assets/uploads/vectorcraft/offset-and-outline.webp)

:::caution
يستبدل Outline Stroke بالحد شكلاً معبأً. لتغيير سماكة الحد بعد ذلك، تراجع عن الأمر أو ابدأ من جديد من نسخة من المسار الأصلي.
:::
