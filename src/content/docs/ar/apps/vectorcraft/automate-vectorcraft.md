يوضح هذا الدليل كيف تعثر على أي أمر بكتابة جزء من اسمه، وكيف تعطي الأدوات والأوامر واللوحات اختصارات لوحة مفاتيح خاصة بك، وكيف تسجل سلسلة من الخطوات إجراءً تستطيع تشغيله مجدداً. ثم يتناول أداة `vectorcraft-cli`، التي تشغّل الأوامر نفسها دون فتح نافذة، وخادم MCP (اختصار Model Context Protocol) الذي تستخدمه برامج أخرى للتحكم في VectorCraft.

## العثور على أمر باسمه

1. اختر **Help → Search Commands…**، أو اضغط **Ctrl+Shift+/** (أو **Cmd+Shift+/** على macOS).
2. اكتب جزءاً من اسم أمر أو أداة، مثلاً «align».
3. اضغط مفتاحَي السهمين لأعلى ولأسفل لتمييز نتيجة، ثم اضغط Enter، أو انقر نتيجة.

يبحث المربع في كل الأوامر والأدوات، ويعرض حتى 14 نتيجة مطابقة، ويعرض اختصار لوحة المفاتيح لكل نتيجة بجانبها. واختيار أداة يجعلها الأداة النشطة، واختيار أمر يشغّله.

![مربع Search Commands وقد كُتبت فيه «align» فوق أربعة فوانيس محددة، ويسرد نتائج مثل Window → Align → Align، وهي مميزة، وAlign left مع اختصار لوحة المفاتيح الخاص به](/assets/uploads/vectorcraft/search-commands.webp)

## تغيير اختصارات لوحة المفاتيح

1. اختر **Edit → Keyboard Shortcuts…**، أو اضغط **Ctrl+Alt+Shift+K** (أو **Cmd+Option+Shift+K** على macOS).
2. في **Set:**، اختر **VectorCraft Defaults** أو **Classic Defaults**.
3. اختر تبويب **Tools** أو تبويب **Menu Commands**، واكتب في مربع **Search** لتضييق القائمة. وتُسرد اللوحات تحت Window في تبويب **Menu Commands**.
4. انقر الاختصار بجانب أحد العناصر، ثم اضغط المفاتيح الجديدة. اضغط Esc للإلغاء.
5. انقر **OK** للاحتفاظ بالتغييرات، أو **Cancel** لتجاهلها.

حين تغيّر اختصاراً، تعرض قائمة **Set:** القيمة **Custom**. وفي النافذة أيضاً هذه الأزرار:

| الزر | ما يفعله |
|---|---|
| **Clear** | يزيل الاختصار من العنصر المحدد |
| **Use Default** | يعيد إلى العنصر المحدد اختصاره الافتراضي |
| **Go to Conflict** | يحدد العنصر الذي أُخذت منه المفاتيح التي ضغطتها |
| **Import…** | يقرأ مجموعة اختصارات محفوظة إلى النافذة؛ اضغط **OK** للاحتفاظ بها |
| **Export…** | يحفظ المجموعة الحالية ملفاً بصيغة `.json` |
| **Reset to Defaults** | يعيد كل الاختصارات إلى مجموعة **VectorCraft Defaults** |

:::note
إذا كانت المفاتيح التي تضغطها مخصصة لعنصر آخر، يزيلها VectorCraft من ذلك العنصر ويعرض رسالة تذكر اسمه.
:::

## تسجيل الإجراءات وتشغيلها

الإجراء قائمة من الخطوات المسجلة. وكل خطوة أمر من أوامر VectorCraft مع الإعدادات التي عمل بها.

1. اختر **Window → Actions**.
2. انقر **Create New Set** أسفل اللوحة، واكتب اسماً وانقر **OK**.
3. انقر **Create New Action**. في **New Action**، اكتب اسماً في **Name:**، واختر المجموعة من **Action Set:**، ثم انقر **Record**. تعرض اللوحة **● Recording**.
4. نفّذ الخطوات التي تريد تسجيلها.
5. انقر **Stop Playing/Recording**.
6. لتشغيل الإجراء، حدده في اللوحة وانقر **Play Current Selection**.

![لوحة Actions بجانب الشارة، وفيها مجموعة اسمها Studio تضم إجراءً اسمه Badge، موسَّعاً ليُظهر خطواته الثلاث المسجلة، shape.ellipse وpaint.setFill وpaint.setStroke، وخانة اختيار كل منها محددة](/assets/uploads/vectorcraft/actions-panel.webp)

وسّع إجراءً لترى خطواته. لكل خطوة خانة اختيار: ألغِ تحديدها لتستثني تلك الخطوة حين يُشغَّل الإجراء، وحددها مجدداً لتضمّنها.

في **New Action** و**Action Options…**، تعيّن قائمة **Function Key:** مفتاحاً من F1 إلى F15 يشغّل الإجراء. ويمكنك أن تضيف **Ctrl** (أو **Cmd** على macOS) و**Shift** إلى المفتاح. وعلى Windows، لا يمكن استخدام F1 وCtrl+F4 وCtrl+F6.

:::tip
مع السرعة الافتراضية **Accelerated**، يُشغَّل الإجراء كله خطوة واحدة في سجل التراجع، فيلغيه Undo واحد. ويقدّم **Playback Options…** أيضاً **Step by Step** و**Pause For**، اللذين يشغّلان خطوة واحدة في كل مرة ويسجلان كل خطوة خطوةَ تراجع مستقلة.
:::

في قائمة اللوحة هذه الأوامر:

| الأمر | ما يفعله |
|---|---|
| **New Action…** | يفتح **New Action**، مثل **Create New Action** |
| **New Set…** | ينشئ مجموعة إجراءات جديدة |
| **Duplicate** | ينسخ الإجراء المحدد، أو المجموعة الحالية حين لا يكون أي إجراء محدداً |
| **Delete** | يحذف الإجراءات أو المجموعات المحددة |
| **Set Options…** | يعيد تسمية المجموعة الحالية |
| **Batch…** | يشغّل الإجراء المحدد على كل ملف في مجلد، أو على كل مجموعة بيانات في المستند المفتوح |
| **Play Current Selection** | يشغّل الإجراء المحدد |
| **Action Options…** | يغيّر اسم الإجراء المحدد ومفتاح الوظيفة الخاص به ولونه |
| **Playback Options…** | يضبط سرعة التشغيل: **Accelerated** أو **Step by Step** أو **Pause For** |
| **Save Actions…** | يحفظ المجموعة الحالية في ملف `.vcactions` |
| **Load Actions…** | يضيف مجموعة محفوظة إلى اللوحة |

في **Batch…**، اضبط **Play:** على **Folder** أو **Data Sets**. ومع **Folder**، اختر مجلداً في **Source Folder:** وحدد **Include All Subdirectories** لتضمين مجلداته الفرعية. ثم اختر في **Destination:** أحد الخيارات التالية:

| الوجهة | ما يحدث لكل ملف |
|---|---|
| **None** | يبقى الملف مفتوحاً |
| **Save and Close** | يُحفظ الملف فوق المصدر ويُغلق |
| **Folder** | يُحفظ الملف أو يُصدَّر إلى **Destination Folder:** ويُغلق |

يوقف **Stop on Errors** المعالجة الدفعية عند أول ملف أو مجموعة بيانات تفشل.

## تشغيل الأوامر من سطر الأوامر

تشغّل أداة `vectorcraft-cli` أوامر VectorCraft دون فتح نافذة. تقرأ ملفاً أو تبدأ مستنداً جديداً، وتشغّل الأوامر التي تسردها بالترتيب، ثم تصدّر النتيجة.

| التثبيت | مكان أداة سطر الأوامر |
|---|---|
| Windows (حزمة MSI) | `%LOCALAPPDATA%\Programs\ArtCraft\VectorCraft\vectorcraft-cli.exe` في التثبيت الافتراضي. ولا يضيفها المثبّت إلى `PATH`. |
| Linux (حزم deb وrpm) | `/usr/bin/vectorcraft-cli` |
| macOS | التنزيل المنفصل `vectorcraft-cli-<version>-macos-<arch>.zip` من الإصدارات. ولا يضم `.app` إلا تطبيق سطح المكتب. |

| الأمر | ما يفعله |
|---|---|
| `vectorcraft-cli commands` | يطبع فهرس الأوامر بصيغة JSON |
| `vectorcraft-cli run --in in.svg --cmd select.all --cmd paint.setFill --params '{"color":"#ff0000"}' --export out.svg` | يفتح ملفاً، ويحدد كل شيء، ويعبئه بالأحمر، ثم يصدّر النتيجة |
| `vectorcraft-cli run --cmd file.new --params '{"width":800,"height":600}' --cmd shape.star --params '{"cx":400,"cy":300,"radius1":200,"radius2":90}' --export star.vectorcraft` | يبني مستنداً جديداً من الأوامر ويحفظه |
| `vectorcraft-cli run --in sheet.vectorcraft --commands steps.json --export out.pdf` | يشغّل الخطوات المسرودة في ملف JSON |

ينطبق كل `--params` على `--cmd` الذي يسبقه مباشرة. ويطبع `run` سطراً واحداً من JSON لكل خطوة، ويتوقف بخطأ عند أول خطوة تفشل، ويذكر تلك الخطوة برقمها، والعدّ يبدأ من 0. ويمكن إعطاء `--export` أكثر من مرة، وامتداد الملف يحدد الصيغة. ولتصدير PNG وغيرها من الصور، يضبط `--scale` عدد البكسلات لكل نقطة (point)، ويضبط `--ppi` عدد البكسلات لكل بوصة. وإذا أُعطي الخياران معاً، يُستخدم `--ppi`. ومن دون أي منهما، تستخدم صادرات الصور دقة التأثيرات النقطية في المستند.

رُسمت النجمة في الصورة التالية وعُبئت وصُدّرت بأمر `vectorcraft-cli run` واحد.

<img src="/assets/uploads/vectorcraft/cli-star.webp" alt="نجمة خماسية كهرمانية على خلفية نيلية داكنة، رُسمت وعُبئت وصُدّرت كلها بتشغيل واحد من سطر الأوامر" width="360" style="display: block; margin-inline: auto;" />

يضم ملف الخطوات الخاص بـ `--commands` مصفوفة JSON من الخطوات، أو خطوة واحدة في كل سطر. وكل خطوة كائن فيه `command`، وهو معرّف الأمر، و`params` اختيارياً. ويمكن أن يضم ملف الخطوات حتى 64 MiB و100,000 خطوة.

```json
[
  {"command": "select.all"},
  {"command": "paint.setFill", "params": {"color": "#2ec4b6"}}
]
```

:::tip
ضع المعاملات الطويلة في ملف خطوات ومرّره بـ `--commands`. ويقرأ `--commands -` الخطوات من الإدخال القياسي.
:::

## التحكم في VectorCraft من عميل MCP

يشغّل `vectorcraft-cli mcp` خادماً لبروتوكول [Model Context Protocol](https://modelcontextprotocol.io)، وهو بروتوكول قياسي يستخدمه عملاء الأتمتة لاستدعاء أوامر VectorCraft. يشغّل العميل الخادم ويتواصل معه عبر الإدخال والإخراج القياسيين.

| الوضع | يُشغَّل بـ | ما يتحكم فيه |
|---|---|---|
| **Connected** | `vectorcraft-cli mcp --connect 127.0.0.1:7979`، مع تشغيل التطبيق بالأمر `vectorcraft --control 7979` | نافذة VectorCraft المفتوحة. ترى كل تغيير لحظة حدوثه. |
| **Headless** | `vectorcraft-cli mcp --headless` | جلسة خاصة به بلا نافذة. والأدوات التي لا تعمل إلا مع تطبيق سطح المكتب، مثل فتح لوحة، غير متاحة. |
| **Automatic** | `vectorcraft-cli mcp` | يجرّب `127.0.0.1:7979` مرة واحدة عند بدء تشغيله، ويعمل دون واجهة (headless) إن لم يستجب أي تطبيق |

لاستخدام الوضع المتصل:

1. أغلق VectorCraft إن كان يعمل.
2. شغّله بمنفذ التحكم:
   - على Windows (في PowerShell): `& "$env:LOCALAPPDATA\Programs\ArtCraft\VectorCraft\vectorcraft.exe" --control 7979`
   - على macOS: `open -a VectorCraft --args --control 7979`
   - على Linux: `vectorcraft --control 7979`
3. انتظر حتى تُفتح نافذة VectorCraft.
4. شغّل عميل MCP لديك مع `vectorcraft-cli mcp --connect 127.0.0.1:7979` أمراً للخادم.

:::note
تشغّل قائمة ابدأ وDock وأيقونات التشغيل على سطح المكتب VectorCraft دون منفذ تحكم. والخادم الذي شُغّل دون أي خيار قبل أن يُفتح التطبيق يبقى دون واجهة حتى يعيد العميل تشغيله.
:::

يحدّ خياران من الملفات التي تستطيع الأوامر استخدامها:

- `--automation-read-root <folder>`: يجب أن يكون كل ملف يقرؤه أمر داخل هذا المجلد.
- `--automation-write-root <folder>`: يجب أن يكون كل ملف يحفظه أمر أو يصدّره داخل هذا المجلد.

يمكن إعطاء كل خيار أكثر من مرة. وصلاحيتا القراءة والكتابة منفصلتان. أعطِ المجلد نفسه للخيارين حين يحتاج العميل إلى القراءة منه والكتابة فيه. ومع `--automation-read-root` وحده، لا تستطيع الأوامر كتابة أي ملف على القرص.

مع `vectorcraft-cli mcp`، يجعل خيارا الجذر الخادم يعمل دون واجهة، ويتوقف الخادم بخطأ إن أعطيت معهما `--connect` أيضاً. ولتقييد جلسة متصلة، شغّل التطبيق بهذين الخيارين بدلاً من ذلك:

```sh
vectorcraft --control 7979 --automation-read-root <folder> --automation-write-root <folder>
```

:::caution
يستطيع العميل المتصل تغيير مستنداتك المفتوحة وحفظها وتصديرها. ومن دون أي من خيارَي الجذر، تستطيع الأوامر قراءة الملفات وكتابتها في أي مكان يستطيعه حسابك. أعطِ جذرَي قراءة وكتابة لا يشملان إلا مجلد المشروع.
:::
