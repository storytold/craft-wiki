![شعار FigCraft](/assets/apps/figcraft.webp)

FigCraft تطبيق لتصميم الواجهات: شاشات التطبيقات، والمواقع، ولوحات المعلومات، وأنظمة التصميم. ترتّب فيه الإطارات، وتبني مكونات تعيد استخدامها، وتربط الشاشات معاً في نموذج تفاعلي قابل للنقر، ثم تسلّم النتيجة للمطورين. يعمل على Windows وmacOS وLinux وFreeBSD وفي متصفح الويب. وهو مجاني ومفتوح المصدر (MIT أو Apache-2.0)، من صنع فريق ArtCraft.

:::note[ألفا]
FigCraft في مرحلة ألفا المبكرة. يعمل المحرر الأساسي من البداية إلى النهاية، لكن ملفات <bdi>.fig</bdi> تُفتح بأفضل ما يمكن دون ضمان، والجلسات المباشرة ما زالت معاينة، ولم يُجرَّب بعد على كثير من ملفات التصميم الحقيقية. احتفظ بنسخة من عملك المهم، وأخبرنا بما يتعطل على [GitHub](https://github.com/storytold/figcraft/issues) أو [Discord](https://discord.gg/artcraft).
:::

## ماذا يفعل

- **التخطيط**: الإطارات، والتخطيط التلقائي (صفوف وأعمدة والتفاف وشبكة)، والقيود، وشبكات التخطيط.
- **المكونات**: المكونات الرئيسية ونسخها المثيلة، والتنويعات، وخصائص المكونات، ولوحة **الأصول**.
- **الأنماط والمتغيرات**: أنماط الألوان والنصوص والتأثيرات والشبكات؛ ومتغيرات الألوان والأرقام والنصوص والقيم المنطقية (صح أو خطأ) مع أوضاع مثل الفاتح والداكن.
- **المتجهات**: أداتا القلم وقلم الرصاص، وتحرير المتجهات، والمجموعات المنطقية، وباني الأشكال.
- **الألوان والتأثيرات**: التدرجات اللونية، والتعبئة بالصور، وأوضاع المزج، والظلال، والتمويه، والتشويش، والنسيج، والزجاج.
- **النص**: يُحرَّر على لوحة الرسم، مع أنماط مختلطة، وقوائم، وميزات OpenType، ونص من اليمين إلى اليسار.
- **النماذج التفاعلية**: التفاعلات، والانتقالات، والمتغيرات مع الشروط، وعرض تقديمي.
- **وضع المطور**: القياسات، والتعليقات التوضيحية، وحالة الجاهزية للتطوير، والكود بلغات CSS وHTML وReact وأطر عمل أخرى.
- **اللوحات**: ملف سبورة بيضاء فيه ملاحظات لاصقة، وأشكال، وموصلات، وقوالب، ومؤقت، وتصويت.
- **الجلسات المباشرة** (معاينة): شارك ملفاً وحرّره مع غيرك. راجع [الجلسات المباشرة](/ar/apps/figcraft/live-sessions/).

## ملفاتك

يحفظ FigCraft ملفاته الخاصة **.figcraft** على حاسوبك. ويفتح أيضاً ملفات <bdi>.fig</bdi> و<bdi>.sketch</bdi> و<bdi>.penpot</bdi> و<bdi>.jam</bdi>، وملفات التصميم المصدّرة بصيغة JSON، وملفات SVG، وصور PNG وJPEG وWebP وGIF وTIFF. ويصدّر الطبقات بصيغة PNG أو JPEG أو WebP أو SVG أو PDF أو XML لرسوم Android المتجهية (vector drawable)، ويستطيع تصدير ملف كامل بصيغة <bdi>.fig</bdi>.

يعمل FigCraft دون اتصال بالإنترنت، بلا حساب ولا قياس عن بُعد. ولا تغادر ملفاتك حاسوبك إلا إذا شاركتها عبر الإنترنت (راجع [الجلسات المباشرة](/ar/apps/figcraft/live-sessions/)).

## ما تحتاجه

- نظام Windows بإصدار 64 بت أو ARM أو 32 بت، أو macOS على Apple silicon أو Intel، أو Linux، أو FreeBSD.
- أو متصفح ويب حديث، لنسخة الويب.
