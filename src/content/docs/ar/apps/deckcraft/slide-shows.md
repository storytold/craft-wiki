## بدء عرض الشرائح

- يبدأ **F5**، أو **Slide Show › From Beginning**، العرض من الشريحة الأولى.
- ويبدأ **Shift+F5**، أو **Slide Show › From Current Slide**، أو **Present** في أعلى يمين النافذة، العرض من الشريحة التي أنت عليها.
- وينهي **Esc** العرض.

يبدأ عرض الشرائح فوراً حين تفتح ملف <bdi>.ppsx</bdi>.

## استخدام طريقة عرض المقدم

شغّل **Presenter View** في تبويب **Slide Show** قبل أن تبدأ. تُفتح طريقة عرض المقدّم في نافذة خاصة بها، فيمكنك وضعها على شاشتك بينما يرى الجمهور الشرائح على شاشة أخرى. وتعرض:

- الشريحة الحالية والتالية، مع **Next** للانتقال،
- ملاحظات المتحدث،
- مؤقتاً، مع **Pause** و**Reset**،
- **Black** و**White** لإظهار شاشة سوداء أو بيضاء للجمهور، و**Zoom** لتكبير جزء من الشريحة، و**All slides** للانتقال إلى أي شريحة، و**End Show**.

## المفاتيح أثناء العرض

| المفتاح | ما يفعله |
| --- | --- |
| **→**، **↓**، **Space**، **Page Down**، **N** أو **Enter** | الحركة أو الشريحة التالية |
| **←**، **↑**، **Backspace**، **Page Up** أو **P** | الحركة أو الشريحة السابقة |
| **Home**، **End** | الشريحة الأولى، الشريحة الأخيرة |
| رقم شريحة، ثم **Enter** | الانتقال إلى تلك الشريحة |
| **G** | عرض كل الشرائح لتختار إحداها |
| **Z** | التكبير |
| **B** أو **.** | شاشة سوداء، والعودة منها |
| **W** أو **,** | شاشة بيضاء، والعودة منها |
| **Ctrl+P** | تشغيل القلم وإيقافه |
| **Ctrl+L** | تشغيل مؤشر الليزر وإيقافه |
| **Ctrl+A** | العودة إلى مؤشر السهم |
| **E** | مسح ما رسمته |
| **T**، **R** | إيقاف المؤقت مؤقتاً، إعادة تعيينه (في طريقة عرض المقدّم) |
| **[**، **]** | تصغير الملاحظات، تكبيرها (في طريقة عرض المقدّم) |
| **Esc** | إنهاء العرض |

على Mac، استخدم **⌘** بدلاً من **Ctrl**.

## التمرن على التوقيتات

اختر **Slide Show › Rehearse Timings** وقدّم العرض كما لو كان حقيقياً. يسجّل DeckCraft المدة التي تقضيها على كل شريحة. ثم حدد **Use Timings** لينتقل العرض وحده.

## إعداد العرض

يختار **Slide Show › Set Up Slide Show** نوع العرض (يقدّمه متحدث، أو يُستعرض في نافذة، أو في كشك)، والشرائح التي تُعرض، وهل يتكرر حتى تضغط **Esc**، وهل تُستخدم التوقيتات. وينشئ **Custom Show** عرضاً مسمّى من بعض الشرائح، بالترتيب الذي تريده. ويستبعد **Hide Slide** شريحة من العرض دون حذفها.

ويعرض **Show Media Controls** أزرار التشغيل والإيقاف المؤقت على الفيديو والصوت أثناء العرض.

## المشاركة دون DeckCraft

لتعطي الآخرين نسخة يفتحونها في أي مكان، صدّر ملف PDF عبر **File › Export › Create PDF Document**، أو احفظ العرض بصيغة <bdi>.pptx</bdi>. ويُنشئ زر **Export** في أعلى اليسار أيضاً صورة GIF متحركة للعرض التقديمي.
