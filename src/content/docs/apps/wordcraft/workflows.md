WordCraft's ribbon groups its tools into tabs: **Home**, **Insert**, **Draw**, **Design**, **Layout**, **References**, **Mailings**, **Review**, **View**, **Developer**, **Zotero** and **Help**. If you can't find a command, type its name into **Search commands and help**.

## Format with styles

Styles keep a document consistent: change a style once and every paragraph using it updates.

- Pick a style in the **Styles** gallery on the **Home** tab. Point at one to preview it.
- Open the **Styles** pane to create a style, or to change one.
- On the **Design** tab, choose a theme or style set to restyle the whole document at once. You can also set the page colour, add a page border or add a watermark there.

![The Design tab showing style-set previews; the document is set in a serif theme with plum headings and a pale diagonal DRAFT watermark](/assets/uploads/wordcraft/design.webp)

**Format Painter** copies formatting from one place to another. **F4** repeats your last action.

## Add tables, pictures and shapes

On the **Insert** tab:

- **Table**: drag across the grid to choose its size. You can then merge and split cells, apply a table style with banded rows, repeat the header row on every page, sort rows and add formulas.
- **Pictures**: resize, crop, recolour, adjust brightness and contrast, or remove the background. Choose how text wraps around it: square, top and bottom, behind or in front of the text.
- **Shapes** and **text boxes** work the same way.

## Lay out pages

On the **Layout** tab, set margins, orientation, page size and columns, and add page, column or section breaks. Headers and footers can differ on the first page, and on odd and even pages.

The tab also has drop caps, automatic hyphenation and line numbers.

![The Layout tab: a drop cap opens the first paragraph, text wraps around a circle and hyphenates at a line end, and every line is numbered in the margin](/assets/uploads/wordcraft/layout.webp)

## Add references

On the **References** tab:

- **Table of contents**: built from your headings. Update it after you change them.
- **Footnotes** and **endnotes**.
- **Citations and bibliography**: in APA, MLA, Chicago or IEEE style. If you keep your sources in Zotero, see [Zotero](/apps/wordcraft/zotero/).
- **Captions**, a **table of figures**, **cross-references** and an **index**.

![The References tab with a table of contents with page numbers on one page and a table, numbered list and link on the next](/assets/uploads/wordcraft/references.webp)

## Review and edit with others

On the **Review** tab:

- **Spelling and grammar** are checked as you type. **F7** goes through every issue. For languages other than English, see [Languages and spelling](/apps/wordcraft/languages/).
- **Track Changes** records every edit with the author's name. Others can then accept or reject each change.
- **Comments** appear as balloons in the margin, or in a pane.
- **Compare** shows what changed between two versions of a document.
- **Read Aloud** reads the document to you, skipping citations and the bibliography.
- The **accessibility checker** finds things that make a document hard to read with assistive technology, such as pictures without alt text.

![The Review tab with Track Changes on: an inserted word in colour and a deleted word struck through, with comment balloons in the margin](/assets/uploads/wordcraft/review.webp)

## Send a mail merge

On the **Mailings** tab, pick your recipient list (a CSV or spreadsheet file), then add merge fields, an address block and a greeting line. Preview the results, then finish to a new document. You can also print envelopes and labels.

## Change how you view the document

On the **View** tab:

- **Read mode** for reading, **Focus** to hide everything but the text.
- **Navigation pane** to jump between headings, or to search the document.
- **Zoom**, one or several pages side by side, rulers and gridlines.
- **Dark mode**.

To change the interface language, choose **File › Options › Language**. By default, WordCraft follows your system's language.

## Keyboard shortcuts

WordCraft uses the shortcuts you'd expect from a word processor. On a Mac, use **⌘** in place of **Ctrl**.

| Shortcut | What it does |
| --- | --- |
| **Ctrl+B**, **Ctrl+I**, **Ctrl+U** | Bold, italic, underline |
| **Ctrl+S** | Save |
| **Ctrl+F** | Search in the Navigation pane |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |
| **F4** | Repeat the last action |
| **F7** | Check spelling and grammar |
| **F8** | Extend the selection |
| **Enter** in a list | Continue the list |
| **Tab** in a list | Indent the item one level |

## Open and save other formats

**File › Open** opens .docx, .doc (Word 97–2003), .odt, .rtf, .html, .md, .tex and .txt. **File › Save As** saves in any of these except .doc. **File › Export** makes a PDF.

Converting between formats can lose some formatting. To share a document that must look the same everywhere, export a PDF.

## Record a macro

A macro records a sequence of steps and plays them back, so you can repeat a task in one go. Find **Record Macro** and **Macros** on the **View** tab.
